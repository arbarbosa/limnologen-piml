# Reproducing the analysis

Entry point: `Limnologen_continuous_OMA_aligned.csv` at the repository root (processed dataset, see `data/README.md`). Everything below runs locally in the `.venv` created by `setup_env.sh` (Python >= 3.10; numpy, pandas, scipy, matplotlib, emcee, numpyro, jax, tinygp, arviz — full list in `requirements.txt`).

> zsh note: do not paste the `#` comments into the terminal.

## One command

```bash
bash reproduce.sh
```

## Stage by stage

```bash
source .venv/bin/activate
python analysis/level0_build_dataset.py --relag Limnologen_continuous_OMA_aligned.csv --out Limnologen_continuous_OMA_aligned.csv
cd analysis
python -c "from pathlib import Path; import level1_adimensional_twin as s; s.run(Path('../aux/level1_adim/v3_per_mode_tau'), per_mode_tau=True, rng_seed=20260609)"
python level1b_split_model.py
python level2_mdof_nuts.py --warmup 1000 --samples 10000 --chains 4
python level3_gp_residual.py --mode 1 ; python level3_gp_residual.py --mode 2 ; python level3_gp_residual.py --mode 3
python level3b_gp_dimensional.py --mode 1 ; python level3b_gp_dimensional.py --mode 2
python fig02_oma_timeseries.py ; python fig04_posteriors.py ; python fig05_split_decomposition.py
python fig06_nuts_diagnostic.py ; python fig07_piml_composite.py ; python fig08_ksweep.py
python fig09_baseline.py ; python fig10_damage_v2.py ; python fig03_architecture_v2.py
```

Supplementary checks: `python checks/synthetic_lag_identifiability.py` (SM S8), `python checks/alpha_prior_sensitivity.py` (SM S2), `python mode_shape_sensitivity.py` (SM S9, Fig. 7c), `python checks/indoor_emc_check.py` (indoor-EMC proxy, Section 5).

With the pinned seeds and the same library versions, the MCMC and GP results reproduce to the printed precision. With other versions of NumPy, emcee or JAX they agree within Monte Carlo error; the weakly identified lag times (for example τ_T of Mode 3) can shift by a few percent.
